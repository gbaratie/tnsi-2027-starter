# Skills étudiants — emplacement réservé

Ce dossier accueillera les futurs guides exécutables destinés aux groupes : modélisation du domaine, RAG, API, tests ou préparation de la soutenance.

Un skill étudiant doit fonctionner avec le starter distribué, sans dépendre des corrections enseignant, de données privées ou des outils internes de production du cours.
